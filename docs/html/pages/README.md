# Page code guides

Each file here explains **this project's actual code** — not general HTML.
Every page is broken down section by section: what the tags do, how the form
behaves, and how the page is reached/navigates.

| File | What it covers |
|------|----------------|
| index.md | Landing page, `#intro` same-page link, mailto contact |
| layout.md | Page template / skeleton for teammates |
| signup.md | Registration form (fields, labels, required) |
| signin.md | Login form |
| home.md | Post-login hub: welcome, notifications, quick actions |
| profile.md | View profile (text + table) |
| edit-profile.md | Edit profile (pre-filled `value=` fields) |
| new-task.md | Create task form (title/desc/priority dropdown) |
| new-team.md | Create team (two fieldsets, one member row + role select) |
| dashboard.md | Progress list + task table + chat button |
| task-details.md | Single task details page |
| chat.md | Team chat shell (empty feed, send box) |

For the overall picture (site flow, how to read any file, tags cheat-sheet,
how forms work, project rules) read the parent guide `../html.md`.
