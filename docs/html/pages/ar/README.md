# أدلة شرح الكود — كل صفحة

كل ملف هنا يشرح **الكود الفعلي لهذا المشروع** — ليس HTML عام. كل صفحة مشروحة
قسماً بقسم: ماذا تفعل الوسوم، كيف يتصرف النموذج، ومن أين تصلك الصفحة وإلى أين
تنقلك.

| الملف | ماذا يشرح |
|-------|-----------|
| index.md | صفحة البداية، رابط نفس الصفحة `#intro`، تواصل mailto |
| layout.md | قالب الصفحات / الهيكل لأعضاء الفريق |
| signup.md | نموذج التسجيل (الحقول، التسميات، required) |
| signin.md | نموذج تسجيل الدخول |
| home.md | محور ما بعد الدخول: ترحيب، إشعارات، إجراءات سريعة |
| profile.md | عرض الملف الشخصي (نص + جدول) |
| edit-profile.md | تعديل الملف الشخصي (حقول معبأة بـ `value=`) |
| new-task.md | نموذج إنشاء مهمة (عنوان/وصف/قائمة أولوية) |
| new-team.md | إنشاء فريق (مجموعتا fieldsets، صف عضو واحد + قائمة دور) |
| dashboard.md | قائمة التقدم + جدول المهام + زر المحادثة |
| task-details.md | صفحة تفاصيل مهمة واحدة |
| chat.md | هيكل محادثة الفريق (رسائل فارغة، صندوق إرسال) |

للنظرة الشاملة (تدفق الموقع، كيف تقرأ أي ملف، جدول الوسوم، كيف تعمل النماذج،
قواعد المشروع) اقرأ الدليل الأم `../../html-ar.md`.
