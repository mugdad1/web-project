# signup.html — نموذج التسجيل

يجمع بيانات المستخدم الجديد: الاسم الأول، الاسم الأخير، الإيميل، كلمة المرور، التخصص.

## وسم النموذج

```html
<form action="home.html" method="get">
```

- `action="home.html"` → عند الإرسال تنتقل الصفحة إلى home.html.
- `method="get"` → القيم المدخلة تظهر في الرابط. لا يُحفظ شيء بعد؛ الحفظ مع PHP + قاعدة البيانات لاحقاً.

## الـ fieldset (مجموعة الحقول)

```html
<fieldset>
    <legend>Account Info</legend><br>
    ...
</fieldset>
```

- `<fieldset>` يجمع الحقول المترابطة؛ `<legend>` عنوان المجموعة.
- `<br>` فاصل أسطر (ينزل النص لسطر جديد).

## الحقول — نفس النمط دائماً

```html
<label for="firstname">First Name:</label><br>
<input type="text" id="firstname" name="firstname" required><br><br>
```

لكل حقل ثلاثة أجزاء مترابطة:

| الجزء | المعنى |
|-------|---------|
| `<label for="...">` | النص الظاهر للحقل. `for="firstname"` يشير للحقل صاحب `id` المقابل. |
| `id="..."` | اسم الحقل الفريد داخل الصفحة — هدف الـ `for`. |
| `name="..."` | اسم الحقل الذي يُرسل للخادم. مهم جداً للـ PHP لاحقاً. |

### الحقول الخمسة

| الحقل | الإدخال | ملاحظات |
|-------|---------|---------|
| الاسم الأول | `type="text"` `required` | صندوق نص عادي، لا يمكن إرسال فارغ |
| الاسم الأخير | `type="text"` `required` | نفسه |
| الإيميل | `type="email"` `required` | المتصفح يتحقق من الشكل؛ الهاتف يفتح لوحة مفاتيح إيميل |
| كلمة المرور | `type="password"` `required` | الأحرف مخفية كنقاط |
| التخصص | `<select>` فيه 4 خيارات | قائمة منسدلة: CS / CN / CIS / CE |

## أزرار الإرسال

```html
<input type="submit" value="Sign Up">
<input type="reset" value="Clear">
```

- `type="submit"` — الزر الذي يرسل النموذج (إلى home.html).
- `type="reset"` — يفرّغ كل الحقول.

## كيف يتصرف النموذج كاملاً

1. يكتب المستخدم في الصناديق ذات التسميات.
2. `required` يمنع الإرسال بينما يوجد حقل فارغ.
3. عند الإرسال، `method="get"` يضع كل `name=value` في الرابط وينتقل عبر
   `action="home.html"`.
4. لا يُحفظ شيء بعد — مرحلة PHP ستقرأ تلك الأسماء.
