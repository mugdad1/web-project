# دليل HTML — مشروع إدارة المشاريع

كل صفحة في موقعنا هي **HTML فقط** — بدون CSS وبدون JavaScript حالياً، نستخدم
فقط ما تعلمناه في المعامل. النماذج تستخدم `method="get"` وتنقلك لصفحة أخرى فقط؛
لا يتم حفظ أي شيء حتى مرحلة PHP + قاعدة البيانات.

---

## 1. كيف تعمل صفحات الموقع

```
index.html  (صفحة البداية)
   |
   |  تسجيل حساب / تسجيل دخول
   v
home.html   (الصفحة الرئيسية بعد الدخول)
   |
   |-- الملف الشخصي -> profile.html  (عرض) -> edit-profile.html (تعديل)
   |-- لوحة التحكم  -> dashboard.html (التقدم + قائمة المهاام)
   |-- مهمة جديدة   -> new-task.html
   |-- فريق جديد    -> new-team.html
   |-- المحادثة     -> chat.html (رسائل الفريق)
   `-- تسجيل خروج   -> يرجع لـ index.html
```

## 3. كيف تقرأ أي ملف HTML

كل صفحة لها نفس الشكل من الأعلى للأسفل:

```
<!DOCTYPE html>          -> تخبر المتصفح أن هذه HTML5
<html lang="en">         -> الصفحة كلها
  <head>                 -> معلومات الصفحة (لا تظهر للزائر)
    <meta charset="UTF-8">   -> يجعل المتصفح يقرأ النص بشكل صحيح
    <title>...</title>        -> النص الذي يظهر في تبويب المتصفح
  </head>
  <body>                 -> كل ما يظهر للزائر
    <header>             -> الجزء العلوي (العنوان + شريط التنقل)
      <h1>...</h1>       -> عنوان الصفحة (أكبر عنوان)
      <nav>
        <a href="...">...</a>  -> رابط واحد لكل عنصر في شريط التنقل
      </nav>
    </header>

    <main>
      <section>          -> كتلة محتوى واحدة
        <h2>...</h2>
        <p>...</p>
      </section>
      <hr>               -> خط أفقي (يفصل بين الكتل)
    </main>

    <footer>             -> الجزء السفلي للصفحة
      <hr>
    </footer>
  </body>
</html>
```

### جدول الوسوم (كلها درّسناها في المعامل)

| الوسم | معناه |
|-------|-------|
| `<h1>` – `<h6>` | العناوين، من الأكبر للأصغر |
| `<p>` | فقرة |
| `<strong>` | نص عريض |
| `<em>` | نص مائل |
| `<a href="file.html">نص</a>` | رابط لصفحة أخرى |
| `<img src="..." alt="...">` | صورة |
| `<ul>` + `<li>` | قائمة نقطية |
| `<table>` `<tr>` `<th>` `<td>` | جدول — صف، خلية عنوان، خلية بيانات |
| `<form action="..." method="get">` | نموذج يرسل لصفحة أخرى |
| `<fieldset>` `<legend>` | مجموعة حقول + عنوان المجموعة |
| `<label for="id">` | وصف مرتبط بمدخل (النقر عليه يركز على المدخل) |
| `<input type="text/email/password">` | صندوق إدخال |
| `<select>` `<option>` | قائمة منسدلة |
| `<button>` | زر قابل للنقر |
| `<hr>` | خط أفقي |
| `<!-- تعليق -->` | تعليق في الكود (لا يظهر في الصفحة) |

## 4. كيف تعمل النماذج حالياً

مثال من `signup.html`:

```
<form action="home.html" method="get">
    <label for="email">Email:</label>
    <input type="email" id="email" name="email" required>
    <input type="submit" value="Sign Up">
</form>
```

- `action="home.html"` → عند الضغط على Sign Up ينتقل الموقع لصفحة home.html
- `method="get"` → القيم المدخلة تظهر في الرابط (تشوفها الآن)
- `required` → المتصفح يرفض الإرسال إذا كان الحقل فارغاً
- الـ `name` + القيمة المدخلة هما ما سيستقبله الخادم لاحقاً (PHP)

حالياً النماذج تنقلك بين الصفحات فقط. الحفظ الحقيقي يأتي في مرحلة
PHP + قاعدة البيانات.

---

## 5. قواعد بسيطة نتبعها

- كل صفحة داخلية لها نفس شريط التنقل ودالة `<footer>` مع `<hr>`.
- جميع روابط "Sign Out" ترجع إلى `index.html`.
- الفريق الجديد فيه صف عضو واحد تعبّئه (إيميل + دور) — لا صفوف وهمية.
- لا روابط ميتة: كل `href` يشير إلى ملف موجود فعلاً.
- الأدوار: **Owner** يدير الفريق، **Admin** يضيف الأعضاء،
  **Member** ينضم ويشارك.
